# Simple TV Box 1.1.0

## English

- Rename PureBox to Simple TV Box / 简单电视.
- English UI by default; automatically use Simplified Chinese on Simplified
  Chinese devices. Localized launcher names, navigation, dialogs and status messages.
- Retain TV remote and touch controls, local watch history and playback resume.
- Retain cached startup previews and background subscription/result refresh.
- No log screen or LAN log server.
- Include English and Simplified Chinese README pages, release/Android/license
  badges, build instructions and Star History.
- Signed, non-debuggable APK for Android 5.0+; ARMv7 and ARM64 in one download.
- Keep the original package ID and local development signing certificate for
  upgrading existing PureBox installations without clearing data.
- Preserve plugin-linked Gson, OkHttp, Okio and Spider APIs in the optimized build.

Provider titles and descriptions are not translated. This is a sideload release,
not a Google Play submission. Signing keys and third-party plugin binaries are
not included in the repository.

## 简体中文

- PureBox 更名为 Simple TV Box / 简单电视。
- 默认英文，简体中文设备自动使用中文；应用名称、导航、对话框和状态文案支持双语。
- 保留遥控器及触屏操作、本地播放记录和观看进度恢复。
- 保留首屏缓存预览及后台订阅／结果刷新。
- 不包含日志页面或局域网日志服务。
- 中英文 README、版本／Android／许可证徽章、构建说明及 Star History。
- 已签名的非调试 APK，Android 5.0+，同时包含 ARMv7、ARM64。
- 保留原包名和本地开发签名证书，旧 PureBox 可覆盖升级，无需清除数据。
- 优化构建保留动态插件依赖的 Gson、OkHttp、Okio 和 Spider 接口。

影视名称及简介由上游提供，不会自动翻译。本版本用于侧载，不是 Google Play 上架版本。
仓库不包含签名私钥和第三方插件二进制。
