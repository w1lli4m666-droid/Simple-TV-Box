# Simple TV Box 1.1.1

## English

- Automatically open Search and Watch history when their top navigation tabs
  receive remote focus; keep top navigation available on both pages.
- Show up to five deduplicated matching titles after a 400 ms typing pause.
  Select a suggestion to search immediately; show an orange loading spinner
  during full searches and ignore stale responses.
- Add local search-history cards with responsive columns, single-entry deletion
  on long press, and a clear-all trash icon fixed above the last column.
  Sparse histories no longer stretch cards across the whole row.
- Fix remote Back on Search and Watch history: return focus to the current
  page's own top tab and reset list scroll before leaving the page.
- Cache first-page previews for every category, reusing category responses
  already fetched for Recently updated, with background refresh.
- Update both English and Simplified Chinese README pages and UI strings.

Android 5.0+; ARMv7 and ARM64 in one signed, non-debuggable APK.
The package ID and signing certificate are unchanged, allowing an in-place
upgrade without clearing watch or search history. No diagnostic screen or
LAN log service is included. Cold starts without a valid preview cache still
require plugin initialization and network access.

## 简体中文

- 遥控器焦点移至顶部“搜索”“播放记录”后自动进入；两个页面均保留顶部导航。
- 输入停顿约 400 毫秒后展示最多 5 个去重后的相关片名，确认后立即搜索。
  完整搜索期间显示橙色转圈动画，防止旧请求覆盖新结果。
- 新增本地搜索记录卡片，多列自适应排列，长按删除单条。
  清空垃圾桶固定在第一行最右侧卡片槽位上方，少量记录不再拉伸整行。
- 修复搜索及播放记录内容区的遥控器返回逻辑：先回到当前页面顶部栏目，列表同时归顶，
  不再直接跳回之前的分类页面。
- 五个分类均支持首屏缓存预览，并复用“最近更新”已经请求的分类列表，后台刷新最新数据。
- 同步更新中英文 README 和界面文案。

支持 Android 5.0+，一个已签名的非调试 APK 同时包含 ARMv7 和 ARM64。
包名及签名证书不变，可覆盖升级，保留播放记录和搜索记录。
不包含日志页面或局域网日志服务。没有有效缓存时，仍需等待插件初始化和网络请求。
