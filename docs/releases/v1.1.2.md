# Simple TV Box 1.1.2

## English

- Fix D-pad focus escaping search-history cards to unrelated navigation tabs,
  especially when only one saved search exists.
- Keep left / right navigation within the current row for search-history cards
  and search results. Focus stays on the edge card when no neighbor exists.
- Update both English and Simplified Chinese README pages.

Android 5.0+; ARMv7 and ARM64 in one signed APK. Package ID and signing
certificate are unchanged, supporting in-place upgrades without clearing history.

## 简体中文

- 修复搜索记录只有一张卡片时，遥控器按右键跳到顶部“剧集”等栏目并自动切页的问题。
- 搜索记录和搜索结果的左右移动限定在当前行；没有相邻卡片时停留原位。
- 同步更新中英文 README。

支持 Android 5.0+，同一个已签名 APK 包含 ARMv7 和 ARM64。
包名与签名保持不变，可覆盖安装，保留播放记录及搜索记录。
