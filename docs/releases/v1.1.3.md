# Simple TV Box 1.1.3

## English

- Invalidate only plugin-loader caches when the downloaded plugin fingerprint
  changes; retain successful caches between app launches.
- Retry an unchanged plugin once with fresh loader caches if initialization fails.
- Bound fallback public-IP lookup time and reuse the result for 60 seconds on
  the same device network, avoiding repeated long waits before playback.
- Normalize episode IDs across the dynamic plugin and built-in API so watch
  history restores the correct episode and playback position after a route change.
- Add logcat-only playback timing diagnostics; no diagnostic page or LAN server.
- Show live video download speed every 0.5 seconds while loading or buffering,
  in preview and fullscreen; hide the indicator when playback is ready.
- Update English and Simplified Chinese documentation.

Android 5.0+; ARMv7 and ARM64 in one signed APK. Package ID and signing
certificate are unchanged. In-place upgrades preserve local history.

## 简体中文

- 根据插件指纹更新对应加载器缓存，避免插件升级后继续使用不兼容的旧缓存。
- 相同插件初始化失败时清理相关缓存并重试一次，成功缓存保留复用。
- 限制内置接口公网 IP 查询的等待时间，同一设备网络下缓存 60 秒，减少播放前的重复等待。
- 统一动态插件与内置接口的集数 ID，切换接口后仍可恢复记录中的正确集数与进度。
- 添加仅供 ADB logcat 使用的播放耗时日志，不恢复日志页面或局域网服务。
- 小窗口与全屏加载、缓冲时，视频中央每 0.5 秒更新下载网速，恢复播放后自动隐藏。
- 同步更新中英文说明文档。

支持 Android 5.0+，同一个已签名 APK 包含 ARMv7 和 ARM64。
包名与签名保持不变，可覆盖安装并保留本地记录。

## Verification

- Eleven Java test suites passed; all 60 translation keys and placeholders match.
- Release build and Android lint passed (0 errors, 37 warnings).
- APK signature verified against the existing signing certificate.
- Installed over wireless ADB on a MiBOX4 running Android 6 / API 23.
- The dynamic plugin initialized successfully and history restored episode 7.
  Playback samples during development reached the first video frame in 3.69 to
  5.95 seconds after opening the playback page. These are observations, not
  performance guarantees.
- An on-device instrumentation check of the release APK observed changing
  download rates (including 87 KB/s, 729 KB/s and 1.1 MB/s) during loading,
  followed by automatic hiding. A fullscreen seek triggered the same indicator
  and it disappeared after buffering. A cold instrumented process took about
  12.7 seconds to become ready, including plugin initialization.
- The temporary instrumentation package was removed after testing and is not
  included in the release APK.
- First startup after an update can still require plugin initialization; source
  availability and CDN/network latency can affect playback time.
